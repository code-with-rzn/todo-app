# To-Do Task Manager

A beginner-friendly To-Do Task Manager built with HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Prevent empty tasks
- Mark tasks as completed
- Delete tasks
- Save tasks using browser Local Storage
- Tasks remain available after refreshing the page

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- Git & GitHub
